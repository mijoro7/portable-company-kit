# 📜 SOP: Onboarding & Replication Flow

## 🏁 Phase 1: The Interview
1. Trigger `bootloader.md` personality.
2. Conduct Business Identity interview.
3. Conduct Tooling Inventory interview.
4. Confirm the "Value Chain" (How a lead becomes money).

## ⚙️ Phase 2: Infrastructure Setup
1. Create `COMPANY_OS.md` from interview data.
2. Populate `TOOLING_MATRIX.md` with verified active tools.
3. Initialize the AgentPulse board (create columns based on the Value Chain).
4. Set up the Rectify Docs root folder.

## 🧬 Phase 3: Employee Installation
1. Deploy `ceo.md` to the core.
2. Deploy `growth`, `sales`, `product`, and `success` DNA files.
3. Map the tool-loadouts to the agents based on the matrix.

## 🚀 Phase 4: The Handover
1. CEO performs a "System Health Check."
2. CEO asks the user for the first "High-Level Goal."
3. Company enters "Active Execution" mode.
